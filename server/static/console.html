Run Polygraph, for real.

This page builds our Docker image and runs it the way the judges will: offline, as user 10001, on 2 CPUs and 6 GB of memory, with a 30-minute limit. It reads the practice rows with every fifth label hidden, then the organisers' own checker inspects the table it hands in, and we compare our labels with the hidden ones.

1What will run

Exactly what scripts/check.sh does, started from this page.

Input1,897 practice sentences about Hooly. 380 of their labels are hidden; the system must label those.
LimitsNo network, read-only disk, 2 CPUs, 6 GB of memory, 30 minutes, as the judges set them.
OutputOne table, output.csv: a label for every hidden sentence, plus 1,000 new claims.
Takes about 2 to 3 minutes.
Docker isn't available on this computer. Install Docker Desktop, start it, and wait until it says “Engine running”.
